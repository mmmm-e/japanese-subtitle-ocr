# 일본어 영상 자막 OCR Studio 사용설명서

앱 상단의 **사용 안내 · F1**에서도 같은 사용 순서와 설정 설명을 확인할 수 있습니다.

## 빠른 시작

### 1. 영상 열기

‘영상 열기’로 MP4/MKV/MOV를 선택하거나 파일을 작업 화면으로 끌어오세요. 영상 열기만으로 전체 OCR이 시작되지는 않습니다.

### 2. 글자가 있는 장면에서 일시정지

재생 버튼이나 재생바로 자막이 잘 보이는 시각을 찾으세요. 영역을 바꾸려면 먼저 재생을 일시정지합니다.

### 3. 초록 자막 영역 지정

초록 영역 밖에서 드래그하면 새 영역을 지정합니다. 안쪽을 끌면 이동, 우측 하단 손잡이를 끌면 크기가 바뀝니다. 모든 글자를 포함하되 배경 여백은 줄이세요. CPT는 한 줄에 가깝게, Paddle은 여러 줄도 시험할 수 있습니다.

### 4. 모델 준비 후 한 장 시험

오른쪽에서 모델과 처리 장치를 고르고 ‘모델 준비 / GPU 확인’을 누릅니다. 최초에는 모델 다운로드로 오래 걸릴 수 있습니다. ‘현재 영역 시험 인식’으로 먼저 결과를 확인하세요. CPU라고 표시되면 GPU로 인식 중인 상태가 아닙니다.

### 5. 전체 영상 추출

Paddle은 우선 1FPS·입력 면적 약 1.0MP·출력 상한 512·전처리 끔으로 시작하세요. ‘영상 전체 자막 추출’을 누르면 프레임 준비 후 OCR이 진행됩니다. 프레임 준비 중에는 인식 진행률이 0%에 머물 수 있습니다.

### 6. 비교·수정 후 저장

재생하면서 추출 자막을 확인하고 아래 표에서 문구와 시간을 고칩니다. ‘파일로 저장’에서 SRT/TXT/JSON을 선택합니다. 나중에 다시 검토하려면 JSON도 함께 저장하세요.

## 좌우 자막 두 개를 한 ASS로 저장

오른쪽에서 **왼쪽·오른쪽 자막 따로 인식**을 켜고 **왼쪽 영역 · 초록**, **오른쪽 영역 · 파랑**을 번갈아 선택하여 각 자막 영역을 지정하세요. 시험 인식은 선택한 쪽만 읽고 전체 추출은 두 영역을 순서대로 처리합니다. 영상 프레임과 GPU 모델은 공유합니다. 자막 시간과 중복 통합은 영역별로 구분하며 같은 문구가 양쪽에 나와도 서로 합치지 않습니다. 처리량은 영역 수에 따라 증가할 수 있습니다.

저장 형식 **ASS · 좌우 위치 포함**을 선택하세요. 한 파일 안에 왼쪽 아래·오른쪽 아래 자막이 동시에 표시됩니다. 원본의 글꼴·색·움직임을 복제하지 않습니다. ASS 지원 재생기가 필요하며 SRT/TXT에는 좌우 위치가 없습니다. JSON을 함께 저장하면 영역·인식 후보·근거 이미지를 다시 검토할 수 있습니다. 영역 모드를 바꾸거나 새 영상을 열면 영역이 초기화되며 영역 위치는 설정 파일에 저장하지 않습니다.

## 중복 정리와 깨진 글자

**현재 결과 중복 정리**는 시간·문구·캐시 이미지의 근거가 충분한 연속 자막을 보수적으로 합칩니다. **선택한 행 합치기**로 같은 영역의 이어지는 행을 직접 묶고 **통합된 인식 후보**에서 대표 문구를 고를 수 있습니다. **중복 정리 되돌리기**는 직전 정리 한 번을 취소합니다. 직접 수정한 문구는 자동 유사 통합에서 보호합니다. 폰트가 표시하지 못하는 글자는 코드 경고가 나오며 OCR 오류와 구분해야 합니다.

ASS에서 중괄호·역슬래시는 서식 명령으로 실행되지 않도록 전각 문자로 표시합니다. 원문은 JSON에 보존합니다.

## 설정값을 바꾸면

### 초당 검사할 장면 수 (FPS)

영상에서 1초마다 몇 장을 골라 자막을 인식할지 정합니다. 재생 화면의 부드러움이나 영상 자체의 FPS와는 별개입니다.

- **올리거나 켜면:** 1 → 3 → 5로 높이면 짧게 나타나는 자막과 변경 시각을 더 촘촘히 확인합니다. 처리할 이미지가 많아져 시간과 프레임 캐시 용량이 늘어납니다. 한 장의 한자 인식 능력이 직접 높아지는 값은 아닙니다.
- **내리거나 끄면:** 1FPS는 약 1초에 한 장이라 빠르게 비교하기 좋습니다. 그 사이에 사라지는 짧은 자막은 놓칠 수 있고 시간 경계도 거칠어집니다.
- **시작값 / 주의:** 시작 권장: Paddle은 1FPS, CPT는 3FPS. 먼저 짧은 구간의 결과를 보고 필요할 때 올리세요. 기본값은 3FPS입니다. VFR 영상에서는 실제 선택 간격이 조금 달라집니다.

### Paddle 입력 이미지 면적 상한

PaddleOCR-VL에 전달할 이미지의 최대 픽셀 면적입니다. 1,003,520은 약 100만 화소(1.0MP)입니다. 가로 길이 100만 픽셀이라는 뜻이 아닙니다. 상한을 넘는 이미지는 비율을 유지해 줄어듭니다.

- **올리거나 켜면:** 작은 획을 더 많이 남길 여지가 있습니다. 이미지 처리와 GPU 메모리 사용량이 늘고 느려질 수 있습니다. 값이 클수록 항상 정확한 것은 아니며 VRAM 부족 오류가 날 수 있습니다.
- **내리거나 끄면:** 처리량과 메모리 부담이 줄어들 수 있습니다. 긴 자막이나 작은 한자의 획이 뭉개져 오인식이 늘 수 있습니다. 원래 이미지가 상한보다 작다면 변화가 거의 없을 수 있습니다.
- **시작값 / 주의:** 시작 권장: 1.0MP(1,003,520). 메모리 부족 시 0.5MP(501,760)로 비교하고, 작은 획이 문제면 1.6MP(1,605,632)까지 시험하세요. 3060 Ti 8GB에서도 다른 프로그램의 GPU 사용량에 영향을 받습니다.

### Paddle 출력 길이 상한 (토큰)

모델이 한 이미지에서 생성할 수 있는 출력 길이의 최대치입니다. 토큰은 모델의 글자 조각 단위라 일본어 글자 수와 1:1로 같지 않습니다.

- **올리거나 켜면:** 긴 문장을 출력할 여유가 생깁니다. 실제로 긴 결과가 생성되면 시간·메모리 사용이 늘어날 수 있습니다. 짧은 문장을 읽을 때 무조건 느려지거나 길게 출력하는 것은 아닙니다.
- **내리거나 끄면:** 지나치게 긴 생성을 제한합니다. 너무 낮으면 정상 자막도 끝까지 읽지 못합니다. 종료 토큰 없이 상한에 닿으면 앱은 잘린 결과를 저장하지 않고 오류를 알립니다.
- **시작값 / 주의:** 기본값 512. 한 줄 자막은 128~256으로 비교할 수 있지만, 길이 제한 오류가 나면 512 이상으로 올리세요. 한자 정확도를 올리는 설정은 아닙니다.

### 대비 조정

글자와 배경의 밝기 차이를 조절합니다. 0은 원본 유지입니다. 이 값은 OCR 신뢰도나 정확도 점수가 아닙니다.

- **올리거나 켜면:** 밝고 어두운 부분의 차이가 강해집니다. 흐릿한 글자가 또렷해질 수 있지만 밝은 획이 뭉치거나 얇은 획·그림자가 사라질 수도 있습니다.
- **내리거나 끄면:** 대비가 약해집니다. 강한 밝기 차이를 완화할 수 있지만 글자가 흐려질 수도 있습니다.
- **시작값 / 주의:** 기본값 0에서 시작하세요. 10~20씩 작게 바꾸고 동일한 장면의 ‘현재 영역 시험 인식’ 결과를 비교하세요.

### 이미지 2배 확대

자막 영역의 가로·세로를 각각 최대 2배로 보간 확대합니다(각 변은 최대 8192픽셀). 원본에 없던 글자 정보를 복원하는 기능은 아닙니다.

- **올리거나 켜면:** 켜면 작은 글자가 커지지만 픽셀 수는 일반적으로 약 4배가 되어 전처리 시간·메모리 부담이 늘어납니다.
- **내리거나 끄면:** 끄면 원래 크기를 유지합니다. 이미 충분히 큰 영상에서는 이 편이 단순합니다.
- **시작값 / 주의:** 기본값 끔. 작은 원본 글자에서만 비교하세요. Paddle의 입력 면적 상한에 걸리면 다시 축소되므로 확대 효과가 줄어들 수 있습니다.

### 흑백(회색조) 변환

색상을 없애고 밝기 정보만 남깁니다.

- **올리거나 켜면:** 켜면 색상 잡음이 줄 수 있지만 글자색과 배경색의 구분도 사라집니다. 컬러 테롭에서는 오히려 불리할 수 있습니다.
- **내리거나 끄면:** 끄면 컬러 입력을 유지합니다. 단, CPT 모델 패키지는 이 옵션과 관계없이 내부에서 회색조로 바꿉니다.
- **시작값 / 주의:** 기본값 끔(원본 컬러). Paddle에서는 먼저 컬러로 시험하고 필요할 때만 비교하세요.

### 선명하게 처리

글자 윤곽을 강조하는 고정 강도의 필터입니다. 숫자로 강도를 조절하는 옵션은 아닙니다.

- **올리거나 켜면:** 켜면 흐린 획을 구분하는 데 도움이 될 수 있습니다. 테두리·노이즈도 함께 강조되어 인식이 나빠질 수도 있습니다.
- **내리거나 끄면:** 끄면 원본 윤곽을 유지합니다.
- **시작값 / 주의:** 기본값 끔. 대비·확대와 한꺼번에 바꾸지 말고 한 항목씩 시험하세요.

### 연속된 같은 자막 통합

추출 완료 시 시간상 이어지는 중복을 정리합니다. 줄바꿈과 유니코드상 같은 자형은 비교할 때 정리하고, 한두 글자가 다른 경우는 반복 관찰과 자막 이미지 근거를 함께 봅니다.

- **올리거나 켜면:** 켜면 잠깐 흔들린 문구를 같은 구간으로 묶고 관찰 횟수가 많은 실제 문구를 대표로 선택합니다. 두 후보가 같은 횟수면 깨진 표시가 적은 쪽을 우선합니다. 원래 후보들은 남고 검토 표시도 유지됩니다.
- **내리거나 끄면:** 끄면 새 추출의 유사 문구 통합을 하지 않습니다. 글자가 완전히 같은 연속 결과는 기존처럼 합칩니다. 설정을 바꿔도 원시 OCR 캐시를 다시 만들 필요는 없습니다.
- **시작값 / 주의:** 기본값 켬. 짧은 문장, 서로 다른 자막이 연속해서 반복 확인된 경우, 빈 시간 구간, 이미지 근거가 부족한 경우는 보수적으로 남깁니다. 기존 결과는 현재 결과 중복 정리로 처리하고, 애매한 경우 왼쪽 행 선택 후 합칠 수 있습니다. 되돌리기는 가장 최근 정리 한 번에 적용됩니다.

### 완전히 같은 이미지 바로 재사용

연속된 자막 이미지의 픽셀이 완전히 같으면 직전 인식 결과를 메모리에서 재사용합니다. 비슷한 이미지를 임의로 건너뛰는 기능은 아닙니다.

- **올리거나 켜면:** 켜면 정지 화면 등에서 반복 처리 부담을 조금 줄일 수 있습니다. 움직이는 배경에서는 같은 자막이어도 이미지가 달라 효과가 작을 수 있습니다.
- **내리거나 끄면:** 꺼도 저장된 OCR 캐시는 재사용합니다. 모델·실제 입력 이미지·설정이 일치하는 결과만 사용합니다.
- **시작값 / 주의:** 기본값 끔. 이 스위치를 켠다고 한자 인식 자체가 개선되지는 않습니다.

## 재생·저장

추출 자막 표시를 켜고 재생하면 현재 시각의 자막이 영상 위에 표시됩니다. 표의 문구와 시간을 편집하면 즉시 반영됩니다. SRT는 시간 포함 외부 자막, TXT는 글만, JSON은 다시 불러와 검토하는 결과 파일입니다. 영상이 바뀌거나 다시 추출하기 전에 직접 편집한 결과를 저장하세요.

## 고급 설정과 문제 해결

모델 버전은 보통 main을 유지하세요. 실행 경로에는 따옴표나 인수를 붙이지 않습니다. 모델·장치·Paddle 상한 변경 후 다음 인식에서 재로딩할 수 있습니다. 설정 저장을 눌러 다음 실행에 유지하세요. GPU 메모리가 부족하면 입력 면적을 낮추고 다른 GPU 프로그램을 줄이세요. 토큰 제한 오류는 출력 상한을 올리거나 영역을 줄여 시험하세요. 전체 설치·오류·캐시 설명은 README.md와 앱의 문제 해결 안내를 참고하세요.
