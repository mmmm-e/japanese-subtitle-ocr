# Synthetic fixtures

이 폴더의 공개 미디어는 테스트용 합성 샘플이며 개인 영상에서 가져온 프레임을 포함하지 않습니다.

- `japanese.png`: Yu Gothic 글꼴로 표시한 `今日は楽しかった！` 한 문장.
- `일본어 test.mp4`: 위 문장을 표시하는 3초 무음 영상.
- `일본어 test.srt`: 위 합성 영상의 한 줄 예시 자막.
- `재생 audio test.mp4`: 영상 패턴과 시험음으로 생성한 4초 재생 테스트.

자막 내용·영상 패턴만 사용하며 영상 컨테이너 메타데이터도 공개 전 확인했습니다. 개인 환경의 OCR 응답 JSON/JSONL 및 로그는 포함하지 않습니다.
